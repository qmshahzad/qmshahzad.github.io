Anthropic Strengthens Claude Enterprise Security Controls

Anthropic, Claude Enterprise, AI security, inference hooks, data loss prevention, enterprise AI, admin controls · 2026-11-07

Anthropic has introduced new security and administration features for Claude Enterprise, including a security center, generally available inference hooks, centralized management and additional access controls. The update lets security teams route prompts and proposed tool calls through existing data-security tools, helping organizations apply data-loss-prevention policies while using AI agents. #Anthropic #Claude #Cybersecurity
